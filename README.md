# 格间

安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

测试：`npm test`　类型检查：`npm run typecheck`　构建：`npm run build`

## 出题工坊

在左侧导航进入「工坊」，亲手绘制黑白数织答案并发布给朋友挑战。

- **绘制与尺寸**：在网格上左键填涂 / 再点取消，可在 5–25 格之间调整尺寸，行列线索实时预览。
- **唯一性验证**：发布前必须通过验证。求解器在 Web Worker 中分片运行（不阻塞界面），结论分为
  - **唯一解**：可以发布；
  - **多解**：展示两份不同解并高亮它们的差异格；
  - **无解**：行列线索互相矛盾；
  - **计算尚未结束（超时）**：预算或时间片用尽，可继续计算——超时绝不等于唯一解。
- **结论与画稿绑定**：每次验证都绑定当前画稿的内容指纹（content key）。画稿一旦修改，旧结论立即失效，不能用于发布；切走页面再回来，画稿与编辑状态保留。
- **发布与版本**：发布后题目进入题库，朋友解出前展柜不公开原图。已发布题被继续修改后再次发布会生成不可变新版本，旧版本及其解题进度、记录保持不变。
- **本地存储**：画稿与已发布题目均保存在浏览器 localStorage，无需登录、无需后端。
